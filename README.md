# CHL-AI-02Pro 人工智能大模型实验箱 · 课程文档

本课程聚焦人工智能与具身智能的前沿应用，以**便携式智能机器人教学平台**（CHL-AI-02Pro）为核心载体，深度融合计算机视觉、语音信号处理、自然语言处理及生成式大模型等关键技术。课程以项目化实战为导向，系统覆盖 **7 大核心技术模块**，内容横跨从基础的视觉引导抓取、语音交互与克隆，到进阶的多模态大模型控制、个性化数字人构建及强化学习桌面整理任务。

> 面向对象：人工智能实验箱课程学习者
> 附：设备演示视频「CHL-AI-02Pro-人工智能大模型实验箱.mp4」（已在本站说明，可联系教师获取）
